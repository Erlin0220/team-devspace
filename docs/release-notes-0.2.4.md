# Team DevSpace 0.2.4

Candidate changes; publication requires fresh final-byte acceptance for all four targets.

- Desktop health keeps five-second local probes while caching successful remote display status for five minutes. Failed remote probes retry after thirty seconds. Manual checks, diagnostics and lifecycle operations remain fresh. The Control Center shows local and remote check timestamps separately. This is not an authorization cache: every MCP request still checks the Gateway's authoritative D1 state.
- Live Windows/Linux acceptance reuses two private test Access Keys per host/platform and resets bindings after each run. Existing file-lock infrastructure serializes pool use. Normal employee revocation records are retained; no revoked credential is resurrected or deleted.
- Publication retains complete local/server integrity checks and installer-side SHA-256 validation. Routine public HTTPS verification uses catalog/checksum identity, HEAD/ETag and bounded first/last ranges. Full independent public-download hashing is available with `--full-https-verify`; bounded probes do not claim to hash the complete public response.
- The website no longer advertises historical installers. After successful stable/script/homepage verification, publication retains stable/auto/minimum policy references and the last known-good predecessor; only unused release directories are removed. A short D1 policy lease, SSH lock and stable CAS protect publication and pruning. Removed pinned URLs cease to work; installed clients are unchanged.
- Enterprise updates use low-frequency client Pull, the existing installer/bootstrap and an independently signed Ed25519 four-platform catalog. Tray/local settings and CLI expose version discovery, manual update and automatic approved-version preference; Gateway/Admin manage auto and minimum support with a grace deadline. Default rollout and minimum enforcement remain disabled for first deployment. Legacy clients need one manual installation to acquire the updater. macOS retains native PKG authorization. See docs/updates.md for boundaries and recovery.

- Public MCP App assets use Cloudflare's native static routing, CORS/security headers and immutable caching for hashed chunks. Control/admin routes remain Worker-first. Deployment verifies public asset hashes and checks that those responses bypass Worker invocation; missing assets and preflight requests retain the existing fallback handler.
- Worker Logs retain 100% of emitted diagnostic events but disable automatic invocation logging. Successful MCP/health/status/static reads and empty cleanup runs no longer produce request logs. Lifecycle outcomes and failures retain severity and request IDs without recording credentials, paths or tool contents. Gateway duration measures response-header preparation, not the full MCP stream.
- The download primary action uses explicit browser architecture hints where available. Uncertain Mac architecture presents Apple Silicon/Intel links, rather than guessing from the frozen Intel UA. Unsupported/mobile environments and disabled JavaScript retain the complete manual platform list. No new dependencies, fingerprinting or Universal packaging are introduced.
- Both native macOS project-folder pickers allow creating directories through AppKit. Selection, cancellation, ownership and controller transaction boundaries are unchanged. The postinstall recovery alert expires after 30 seconds instead of blocking Installer indefinitely when no user dismisses it.
- Failed Cloudflare management API calls report HTTP status or network failure and numeric provider codes only, without provider response text or credentials. This distinguishes upstream outages from application failures while preserving fail-closed cleanup.

Acceptance remains source- and final-byte-bound; consult each artifact receipt rather than inferring test or deployment success from these release notes. macOS Intel validation on the hosted Apple Silicon build machine uses Rosetta and is not a physical Intel Mac test.

Implementation references: Cloudflare Workers Static Assets routing, headers and Workers Logs documentation; Chromium `components/embedder_support/user_agent_utils.cc` (`GetCpuArchitecture` distinguishes translated Intel on Apple Silicon); Apple AppKit `NSSavePanel.canCreateDirectories`. The existing independent software-download and post-install authorization flow remains aligned with Tailscale's public installation flow, without adding its infrastructure.
