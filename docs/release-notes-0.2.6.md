# Team DevSpace 0.2.6

- 控制中心端口冲突时独立降级；记住可用端口，跨端口时轮换本机访问凭据，升级后的原页面可重新连接。
- 检查更新展示新版说明与确认弹窗；改进下载、系统安装授权、短暂离线及重连状态，避免重复启动安装器。
- 修复日志不可写、界面回调或版本库存上报异常影响核心连接的问题；缓存损坏允许重新获取，不降低身份、授权和签名校验。
- macOS 重开已安装应用不再重装并重启健康服务；日志失败使用空输出降级，不重复执行应用。
- 退出和回滚尽量清理各自拥有的组件；一项清理失败不跳过其他组件，也不允许未停止的候选版本被删除或重复启动。
- 切换项目目录失败时，必须确认旧进程停止且原配置恢复完整后才允许重启；首次绑定中的托盘登录项故障不再阻断核心连接。
- 重新打开应用可单独修复缺失的托盘启动项，不再为此重装或重启健康核心服务；发布清理保留升级验收所需的固定旧版本基线。
- 保留设备绑定、Access Key、项目目录和暂停意图；继续使用既有安装器、签名元数据、完整 hash 与平台验收链。

当前内部免费发行的 macOS PKG 未采用 Apple Developer ID 签名或公证。x64 在 M2/Rosetta 上的验收不等同于 Intel 实机验收；具体证据与限制见本版本 acceptance 文件。自动推广和最低支持版本仍由管理员独立控制。
